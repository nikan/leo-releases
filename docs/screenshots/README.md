## Screenshot Guidelines

When adding screenshots:

1. **Format**: Use PNG format for best quality
2. **Resolution**: Minimum 1280x720 for desktop screenshots
3. **Naming**: Use descriptive names (e.g., `installation-windows-step1.png`)
4. **Organization**: Group related screenshots in subdirectories
5. **Documentation**: Update this README with descriptions

## Contributing Screenshots

If you'd like to contribute screenshots:
