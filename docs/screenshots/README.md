## Screenshot Guidelines

When adding screenshots:

1. **Format**: Use PNG format for best quality
2. **Resolution**: Minimum 1280x720 for VSCode window screenshots
3. **Naming**: Use descriptive names (e.g., `vscode-marketplace-installation.png`)
4. **Organization**: Group related screenshots in subdirectories
5. **Documentation**: Update this README with descriptions
6. **Context**: Capture the VSCode window with relevant context

## Contributing Screenshots

If you'd like to contribute screenshots:

1. Ensure screenshots don't contain sensitive information
2. Use high quality, clear images
3. Capture the full VSCode window or relevant panel
4. Follow the naming convention
5. Update this README with descriptions
6. Submit via pull request or issue

## Notes

- Screenshots should show the extension within VSCode context
- Screenshots should be optimized for web viewing
- Avoid including personal or confidential information
- Use annotations to highlight important features when helpful
- Consider using VSCode's light and dark themes for variety
