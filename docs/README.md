## User Guide

### Using Leo in VSCode

After installing the Leo extension in Visual Studio Code:

1. **Activate Leo**: Use the Command Palette (Ctrl+Shift+P / Cmd+Shift+P) and search for "Leo"
2. **Access Leo features**: Look for Leo in the VSCode sidebar or activity bar
3. **Configure settings**: Open VSCode Settings and search for "Leo" to customize the extension

### Common Commands

Access Leo commands through the VSCode Command Palette:

- Search for "Leo" to see all available commands
- Configure Leo settings in VSCode preferences
- Check extension status in the Extensions view

### Extension Features

Leo provides the following features within VSCode:
- AI-powered workflow assistance
- Context-aware suggestions
- Integration with your VSCode workspace
- Seamless editor integration

## Frequently Asked Questions

### How do I update the Leo extension?

The easiest way is through VSCode:
1. Open Extensions view (Ctrl+Shift+X / Cmd+Shift+X)
2. Find Leo in your installed extensions
3. Click "Update" if an update is available

Alternatively, download the latest `.vsix` from the [releases page](https://github.com/nikan/leo-releases/releases) and install manually.

### How do I verify my download?

For manual installations, see the [verification instructions](../README.md#-verification) in the main README.
