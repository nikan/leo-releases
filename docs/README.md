## User Guide

### Basic Usage

After installing Leo, you can start using it from your command line:

```bash
# Display help and available commands
leo help

# Show version information
leo --version

# Start Leo
leo
```

### Common Commands

```bash
# Get help for a specific command
leo help <command>

# Configure Leo
leo config

# Check for updates
leo update
```

## Frequently Asked Questions

### How do I update Leo?

Download the latest version from the [releases page](https://github.com/nikan/leo-releases/releases) and replace your existing installation.

### How do I verify my download?

See the [verification instructions](../README.md#-verification) in the main README.

### Where can I report bugs?

Please report bugs through the GitHub Issues page or follow our [security policy](../SECURITY.md) for security-related issues.

### Is Leo free to use?

Yes, Leo is distributed as freeware. See the [LICENSE](../LICENSE) for complete terms.

### What platforms are supported?

Leo supports:
- Windows (64-bit)
- macOS (Intel and Apple Silicon)
- Linux (x86_64 and ARM64)
